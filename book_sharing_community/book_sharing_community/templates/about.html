Project Documentation

Book Sharing Community Web Application

A Semester Mini-Project built with Python, Flask, and SQLite

1. Problem Statement & Motivation

College textbooks, reference manuals, and popular novels are often expensive and only needed for a single academic semester or a short reading period. Once read, these valuable physical copies remain idle on student shelves, while other students struggle to source the same books.

BookShare solves this issue by establishing a peer-to-peer campus book lending network. It connects book owners with students looking for reading material, drastically cutting textbook expenses, promoting knowledge reuse, and encouraging eco-friendly sharing habits across campus.

2. Architecture & Technology Stack

Backend & Framework
  • Python 3.14: Core programming language.
  • Flask 3.x: Lightweight WSGI web application framework utilizing the Model-View-Controller (MVC) blueprint pattern.
  • Flask-Login & Werkzeug: Secure session handling and password hashing (PBKDF2/scrypt).
Database & Storage
  • SQLite: Zero-configuration, serverless, transactional relational database engine.
  • SQLAlchemy ORM: High-level Python Object-Relational Mapper preventing raw SQL injection vulnerabilities and enforcing relational integrity.
Frontend & UX
  • Jinja2: Server-side template engine for rendering dynamic views.
  • Bootstrap 5 & Bootstrap Icons: Modern, responsive UI optimized for desktops, tablets, and smartphones.
Security & Integrity
  • Salted cryptographic password hashing.
  • Protection against self-borrowing and duplicate active requests.
  • Automated cascade deletions and strict status transitions.

3. System Modules

Enables students to sign up, log in securely, update contact numbers, hostel/campus locations, and manage their personal library of listed books.

Complete CRUD capabilities for books. Readers can search titles or authors via live queries and filter by Genre, Physical Condition (Like New, Good, Fair), and Availability.

State-machine managing requests: Pending → Approved → Returned (or Declined). When approved, the book is automatically marked as unavailable; when returned, availability is restored.

Peer feedback loop allowing users to rate books from 1 to 5 stars, review usefulness, and calculate dynamic community averages for all catalog entries.

4. Future Enhancements

  • Push / SMS Notifications: Automatic reminders 2 days prior to the return due date.
  • Campus Geolocation Distance: Sorting available books by proximity (e.g., Hostels vs Day-Scholar departments).
  • AI Book Recommender: Recommending relevant books based on previous borrowing patterns and curriculum syllabi.
